    - 自分でさっさとマージして良いです

## 秘密情報 (トークン・鍵・パスワード)

- このレポジトリは公開されている. トークン, API キー, パスワード, 秘密鍵, 認証付き URL などの秘密情報は絶対にコミットしないこと
    - 漏れると困る値がある前提で運用する
- 秘密情報はコードに直書きせず, 環境変数やレポジトリ外のファイルから読み込む
    - 秘密を含むファイル (`.env`, `*.key`, `secrets.*` など) は `.gitignore` に入れる
- コミット前に `git diff --staged` を見て, 秘密情報が含まれていないか必ず確認する
- ログ, 設定ファイル, スクリーンショット, 出力例にも秘密情報が混ざっていないか注意する
- 万一コミット・プッシュしてしまったら, 履歴から消すだけでは不十分. すぐにユーザーに報告し, その秘密情報を無効化 (再発行) する
